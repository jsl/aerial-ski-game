   `capture.js` → `verify.js` (**verify.js is always the last command before committing**).
4. Gates, detached with a completion marker (the Bash tool caps at 10 min; the drive set takes 15–25 min):
   ```
   setsid nohup bash -c "cd ~/aerial-agents/integ && DRIVE_PORT=8396 npx playwright test \
     --config tests/drive/playwright.config.js <specs> > $SC/cand_full.log 2>&1; \
     grep -E 'passed|failed|Error' $SC/cand_full.log; echo CAND_DRIVE_DONE" > $SC/cand_drive.log 2>&1 &
   ```

   then watch `cand_drive.log` with a Monitor. Ports: reviewer 8393–8397, Opus 8399, GLM default. **Never**
   use 8200–8203 (viewers) and always `fuser -k <port>/tcp` first — a stale server makes Playwright die with

## 6. Process rules that were learned the hard way

- **`node tests/golden/verify.js` is the last command before every commit.** Iteration 121 committed traces
  that did not match its own tree (17/30) because the capture ran before a later edit.
- **A display-only trace re-capture must be proven**: `audit-physics-state.js` = 0 physics-state diffs, and
  say "census-only" in the message.
- **Parked items stay parked** (138 landed a rewire that was explicitly parked, and it caused the P0 bug).
- **Review-only iterations do not edit source** (135 left `game.js` dirty at its deadline and blocked a
  landing).
- **Instruments lie more often than the renderer.** This session alone: the ridge contrast gate measured
  background; the face gate passed on pictures of trees; the fold gate measured boot edges; the bib gate
  measured a lighting difference; the grey-ramp gate measures mirrored rows; the pose-shot harness computed
  a −14.29 m stand-off and shot the athlete from inside the snow. **Every new gate ships with a negative
  control that actually fires.**
- **`pkill`/`pgrep -f` patterns must live inside a helper script** (e.g.
  `~/aerial-agents/scratch/fable/kill_cand.sh`) or they match the calling shell and kill it (exit 144).
- Known flaky: `crash-ragdoll.spec.js` penetration/settle under parallel SwiftShader load (it was flaky on
  GLM's own tip, 1/3 green, before 126–128 made the roll deterministic); `look.spec.js` times out at 7 min
  when another suite is running — re-run it alone before believing a failure.
